# 001 Character

**Decision.** Merel is a geometric blackbird built from discs and rounded bars, in a tailcoat with a white shirt front and a red bow tie: a maestro who sings. Luk, 2026-11-13.

**Why.** Built shapes keep the clear-line edge of Joost Swarte and animate cheaply. A bird and not a human: a beak opening reads as "now singing" at any size. A more naturalistic blackbird with a long tail was tried the same day and dropped: it drifted from the rest of the system.
