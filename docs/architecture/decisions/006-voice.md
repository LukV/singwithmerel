# 006 Merel's voice

**Decision.** Merel sings each note by its name (do, re, mi), not on "ooh". In recognition he sings on a neutral "du", so the name does not give the answer away. English uses "ti" for the seventh note, French and Dutch "si". The clips are produced by an AI singing voice and dropped into the code tree as files. Luk, 2026-11-14.

**Why.** Singing the name is how solfege is learned. "du" is how a teacher dictates. The spec is [[0010-voice-clips]].
