# 002 Look

**Decision.** Black and paper carry everything; lettering is hand-drawn; colour appears only as an ink dot that belongs to one note, the same colour wherever that note appears. Print Club London's identity is the main reference. Luk, 2026-11-13.

**Why.** Earlier rounds (a cream Swarte sheet, a Muntpunt-style colour bands and Persepolis mix, a night-lab and a Japanese print direction) were either generic or too loud. Colour tied to notes gives it a job and keeps it calm.
